## 🛠️ Installation & Setup

Set this up on your own machine or VPS. Simple words, simple steps. 

### Step 1: Install Dependencies
Open your terminal and run this command to get all required packages:
```bash
pip install -r requirements.txt
```

### Step 2: Configure Your Environment
Open the `.env` file and put in your own details. Make it yours:
```ini
# Your Telegram Bot Token from @BotFather
BOT_TOKEN = "your_bot_token"

# Your Telegram Account ID (Makes you the Owner)
ADMIN_ID = "123456789"

# The name of your Bot
BOT_NAME = "AccStore QR Bot"

# The Bot's Username
BOT_USERNAME = "@AccStore_QR_Generator_bot"
```

### Step 3: Launch
Start the bot and watch it come to life:
```bash
python main.py
```
